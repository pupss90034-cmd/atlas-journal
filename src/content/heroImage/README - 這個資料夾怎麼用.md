# 這個資料夾放什麼？

**所有文章的封面圖。** 只放封面，內文照片還是照舊直接拖進 Obsidian 筆記裡就好。

## 怎麼用（兩步）

1. 把想當封面的照片丟進這個資料夾（桌面上的 `heroImage` 捷徑就是指到這裡）。
2. 在文章的 frontmatter 只寫**檔名**：

```yaml
---
title: 大溪地的第一印象
description: 散落在太平洋上的珍珠
pubDate: 2024-10-05
heroImage: DSC_0271.JPG
---
```

不用寫路徑、不用管文章放在第幾層資料夾，寫檔名就會自動對應到這裡的圖。

## 幾件不用擔心的事

- **檔案很大沒關係。** 直接丟相機原始檔（5～7MB）就好，Astro 建置時會自動壓縮成 webp、
  產生多種解析度，讀者實際下載到的檔案很小。
- **大小寫打錯沒關係。** `dsc_0271.jpg` 也找得到 `DSC_0271.JPG`。
- **不小心貼成路徑或 `[[檔名]]` 也沒關係**，會自動處理掉，只取檔名。
- **留空沒關係。** 沒填封面的文章會用預設封面（`src/assets/site/default-cover.jpg`）。
- **打錯字不會讓網站建置失敗。** 找不到圖的話會先用預設封面，並在建置訊息裡印出
  `[heroImage] 找不到封面圖…` 提醒你。

## 建議的檔名習慣

檔名就是你在文章裡要打的字，所以取好一點會比較好找。例如：

- `2024-大溪地-海灣.jpg`
- `2026-露營車-01.jpg`

## 背後怎麼運作的

檔名對應到實際圖檔的邏輯在 `src/utils/heroImage.ts`，
frontmatter 的欄位定義在 `src/content.config.ts`。平常不用動它們。
