── 這一區長什麼樣 ─────────────────────────────────

  ① 頭條（Featured）
     左邊一張 4:3 大圖，右邊一整欄文字：
       分類 · 日期  →  篇名  →  摘要  →  幾分鐘讀完  →  Read the essay →
     右上角另外有一個「All Writing →」直接通往 /blog。

  ② 最新文章（Latest）
     左邊是區塊標題，右邊是一列分類（All／旅行隨記／路上觀察⋯）。
     點一個分類，底下的格線就地換一批，不會換頁也不會重新載入。
     格線是三欄（手機一欄、平板兩欄），最下面一顆「Browse the Archive」。

── 每個欄位是什麼 ─────────────────────────────────

  featuredEyebrow    頭條左上角的小字
  archiveLinkLabel   頭條右上角通往 /blog 的字（後面的箭頭是自動加的）
  featuredCtaLabel   頭條文字最下面那個連結的字樣
  featuredTitle      想固定某一篇當頭條，就在這裡填那篇的標題。
                     不用打完整，打幾個關鍵字就會比對到，例如：聖家堂
                     留空 ＝ 永遠自動用最新發佈的那一篇（建議留空）。
                     填了但找不到，會自動退回最新那篇，不會讓網站壞掉。

  eyebrow            格線那一段的小字
  heading            格線那一段的標題（會自動轉成大寫大字距）
  allLabel           分類列最左邊那顆「全部」的字樣
  ctaLabel           最下面那顆按鈕的字樣
  gridCount          格線最多露出幾篇。填 3 的倍數（3／6／9）版面最整齊。
                     這是「不論選哪個分類都最多顯示幾篇」的上限。
  showReadingTime    要不要顯示「8 MIN READ」。不想要就改成 false。
                     （/blog 那一頁另外有自己的開關，兩邊互不影響）
  emptyText          某個分類目前沒有文章時顯示的那一行字

── 建議字數 ───────────────────────────────────────

  featuredEyebrow / eyebrow    1–2 個英文字
  heading                      12–24 個英文字元（會被拉開字距，太長會換行）
  archiveLinkLabel / ctaLabel  2–3 個英文字
  emptyText                    12–20 字

── 為什麼文章從第四區搬到第二區 ───────────────────

原本首頁的順序是「封面 → 關於我 → 去過哪裡 → 文章」，那是自我介紹的
順序，適合一個已經認識你的人。第一次進站的讀者要的是「這裡有什麼可以
讀」，先看三段自我介紹才看到第一篇文章，很多人在那之前就離開了。

現在的順序是：封面 → 文章 → 攝影集 → 關於我 → 去過的地方 → 顧問服務
與販售包 → 電子報。先給東西看，再說自己是誰。
